# Titanic: Machine Learning Survival Prediction

Проект по анализу данных и построению модели машинного обучения для предсказания выживаемости пассажиров «Титаника».

🎯 Задачи:

· Провести разведочный анализ данных (EDA).
· Выявить ключевые факторы выживания (пол, класс, возраст).
· Обучить модель классификации (Random Forest).

🛠️ Инструменты:

· Python (pandas, numpy, matplotlib, seaborn)
· Scikit-learn (RandomForestClassifier)

📊 Результаты:

· Точность модели: 80.4%.
· Наибольшее влияние на выживаемость оказали: цена билета, пол и класс каюты.

🚀 Как запустить:

1. Установите зависимости: pip install pandas scikit-learn matplotlib seaborn
2. Запустите скрипт: python titanic.py
